## MODEX GLOBAL FIGURE MASTER V3

适用于 `paper-figure`、`paper-figure-html`、`nature-figure`、`experiment-bridge`。目标是让图表既可追溯又有稳定的编辑审美；这是一份执行契约，不是图型或 panel 数量配额。

### 1. 先保留视觉母版，再增量修改

- 若工作区已有可读的 `gen_fig_*.py` 和同名图，先把它们当作**视觉母版**：保留其版式骨架、主次关系、留白、字体尺度、语义色、特殊 marker 和自然批注。
- 只有以下原因允许重写图或脚本：数据源错误/代理结果、图型与真实数据语义冲突、可读性硬伤、数字或单位不一致、用户明确要求重构。
- 更新数据或补证据时，优先在原图内替换数据层、添加一个真正互补的 inset/投影/摘要，不得为了“遵循新规则”把整批图降格为通用 matplotlib 草图。
- 全面重写前，先读取原脚本和相应 JSON 字段；在 `_tmp/FIGURE_CHANGELOG.md` 用三行记录“保留什么、改变什么、为什么”。

### 2. 编辑结构优先于元素堆叠

- 先写读图任务，再选几何和排版：读者要完成的是比较、排序、分布、关系、组成、前沿或流程中的哪一种判断？多面板应沿一条论证路径组织，通常为“对象/方法 → 主要结果 → 统计或约束验证 → 机制/决策”。
- 每张图只服务一个主问题。高信息密度来自互补证据，不来自对称 2×2 拼图、颜色、注释或重复 panel。
- 复合图应有明确等级：一个主 panel 占视觉重心，辅助 panel 只解释差异、约束、机制或不确定性。若单图最清楚，保留单图。
- 先压缩共同模式，再展开异常、阈值、转折、选中项或机制节点。标签只标这些证据锚点，解释性句子进入图注。
- 3D 默认拒绝：只保留真实空间、时间、轨迹或不可替代的第三连续变量；必须记录 `geometry_semantics`、视角、遮挡风险和 2D 投影/切片/离平面摘要。离散阶段、类别编号、项目编号不得被平滑成曲面；尖峰/稀疏点优先用 2D、热图、切片或 small multiples。
- 稀疏网格只展示真实格点、热图、切片或离散 3D；不得用高等级 `contourf`、插值曲面伪造高分辨率结构。
- 美术式留白转成工程约束：组内间距小于组间间距，主证据占最大有效区域，辅助层降饱和/透明度，四周给标签方向留安全边界；黄金比例只作构图启发，不改数据尺度。
- 用接近、相似和连续建立可预测节奏：相同语义保持相同颜色/marker/线型；异常只能因数据证据打破节奏；不要让每个 panel 同时改变轴、颜色、标记和标注方式。先支持总体发现，再提供少量数值确认。

### 3. 稳定视觉语法

- 纯白背景、深灰文字、淡网格；高饱和色只用于 1–2 个关键对象，其余降饱和。
- 连续变量使用单一顺序色图；偏差使用以零为中心的发散色图；类别使用固定离散色和 marker/线型辅助。不得将多种颜色的透明叠加做成“彩色线团”。
- 流图先排序节点以减少交叉；小流合并或降级到附录；节点名称、总量和流带分层排版。流入流出若不守恒，先 BLOCK，不用视觉补救。
- Pareto 图必须先处理可行性，再算非支配集；背景候选浅灰低透明，前沿单一强调色，最多标极端/膝点/基准/选择等 4 个关键点；2D 前沿排序后连线，3D 默认只散点+投影；参数扫描曲线不得误称 Pareto。
- HTML/SVG 示意图优先使用显式 grid/viewBox、固定列宽/行高/箭头锚点和一条主阅读路径；每节点最多标题+一行副信息，详细解释移到 caption/正文；最终检查单栏、双栏和缩小视图。
- 图内文字保持短：对象、数值、事件或机制。坐标、图例、色条与数据不能互相遮挡。

### 4. 数据与导出红线

- 所有数值来自当前 JSON、附件或真实日志；代理、占位、手抄、随机重构结果不得进入正式图。
- 图表输出一律使用工作区根下的 `figures/fig_<id>.pdf` 与 `figures/fig_<id>.png`。脚本位于 `figures/` 时不得再写 `figures/fig_...` 造成 `figures/figures/` 嵌套。
- PDF 与 PNG 必须属于同一次渲染：脚本可以直接双格式保存；若脚本只生成 PDF，生命周期会自动从该 PDF 生成同名 350 DPI PNG，不能把 `_tmp` 预览图冒充正式 PNG。
- 正式 HTML 机制图以 HTML 为唯一源，旧占位 Python 不得覆盖它。
- 画完后必须检查数据来源、单位/守恒、输出路径、标签可读性和视觉层级。发现 REVIEW 时先修构图或脚本，再宣布完成；BLOCK 必须停止发布。
